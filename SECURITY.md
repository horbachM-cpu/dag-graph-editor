# Security Policy

## Supported Versions

This repository does not currently maintain multiple supported release lines. Security fixes, when available, are expected to land on the current default branch.

## Reporting a Vulnerability

If you believe you found a security issue, please avoid opening a public issue with full details.

Use a private GitHub contact path to the repository owner if one is available. If that is not possible, open a public issue only after removing sensitive details and enough information to reproduce the problem safely.

## Scope

This project is a local desktop application. Reports are most useful when they include:

- affected operating system
- Python version
- the graph file or input pattern involved, if relevant
- exact reproduction steps
